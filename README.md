# BLOXEN

**Unofficial, non-commercial preservation project. Not affiliated with, endorsed by, or sponsored by Roblox Corporation.**
"Roblox" and related marks belong to Roblox Corporation. BLOXEN reconstructs the *July 2015* Roblox experience for
historical preservation and research, using only publicly preserved material and independently written code.

Target: Roblox Windows Player `0.205.0.61876` (deploy `version-0d46087630eb46cd`, 23 July 2015).

See `STATUS.md` for what is DONE / PARTIAL / BLOCKED / NOT STARTED, and `research/` for the evidence behind every
historical claim. Every component is graded PRESERVED / ARCHIVED-EXACT / ARCHIVED-NEAR-DATE / RECONSTRUCTED-FROM-EVIDENCE /
INFERRED / UNKNOWN. Test results are labelled UNIT-TESTED / SIMULATOR-TESTED / REAL-CLIENT-TESTED; no simulator result is ever
presented as historical-client compatibility.

Quick start: `npm test`, then `npm start` (web + compat backend on 127.0.0.1:8080).

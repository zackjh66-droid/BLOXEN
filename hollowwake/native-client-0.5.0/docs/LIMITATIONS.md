# Current limits

- The user reported working Xbox account linking in an earlier release. Fortnite's entry point, original loading screen and lobby have not been demonstrated.
- The last retrieved Xbox report was 0.5.3: 838 platform pairs, 42 unavailable, including 16 main-image pairs. Five implemented adapters project 37 remaining/14 main; this is not a new Xbox measurement. DirectSound's three bindings have later real-provider integration under test and are not silently counted as Xbox-resolved.
- The fixed original import inventories remain intact. Normal imports across dependencies block loading. Delay-only unavailability stays reported and fails through the original Windows delay-loading path if requested; it is not implemented functionality.
- Remaining families include WGL, legacy IMM input-context/metadata operations, compositor synchronization, D3D9, Bluetooth and Windows network diagnosis. A placeholder export, `E_NOTIMPL` thunk or constant success is not a completed implementation.
- Twelve desktop-only bindings now have typed native delegation/failure adapters. If native IMM/WGL/D3D9/compositor APIs are absent, they return explicit API-shaped failure and remain marked `nativeCapabilityUnavailable`. This does not implement those features or prove the original client tolerates their absence.
- New audio/graphics providers bring additional imports. Their dependency inventories and actual packaged tests are required; Windows export presence is not Xbox behavior evidence.
- All 139 selected data files/26,449,827,840 bytes matched the preserved archive during a full streaming hash audit. Actual Xbox downloading, storage allocation/quota, pause/resume and a final device on-disk receipt still need device evidence. No ready marker alone proves content exists.
- Hollowwake registration/linking is preserved. It is not Fortnite OAuth, profile, catalog or XMPP presence. The guest receives no Hollowwake refresh token. Original character rendering, locker/shop behavior and profile persistence are not yet verified.
- Matchmaking remains unavailable. The companion is not presented as a completed Fortnite port.

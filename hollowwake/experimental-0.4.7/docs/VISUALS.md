# Visual assets and evidence

The background is the unmodified official Epic Chapter1 Season6 cube/corrupted landscape promotional image linked in Epic's September27,2018 Season6 announcement: https://www.fortnite.com/news/season-6?lang=en-US . It matches the scene supplied in the launcher reference. It is not a Loot Lake island screenshot and is not AI-generated. See VISUAL-SOURCES.json for exact CDN URL, SHA-256 and source.

Usage is conditional noncommercial fan content under https://legal.epicgames.com/epicgames/fan-art-policy . Required disclaimer appears on every page and launcher. This is not public-domain art or authorization to redistribute Fortnite executables, modify Epic services or sell this project. No ads or payment features were added. The original private game archive remains unchanged and is not included.

The HW mark is an original transparent SVG reconstruction of the owner-supplied branding reference. Website and UWP render separate live HOLLOWWAKE text using Anton Regular (SIL OFL1.1); font and license are included. This is condensed display lettering, not Epic's proprietary font. The whole mockup was not flattened into an image.

Website screenshots come from Chromium against the deployed implementation. Native screenshots, when available, come from the actual installed UWP process on hosted Windows via UI Automation and screen capture. Neither proves Xbox execution or an original Fortnite lobby.
